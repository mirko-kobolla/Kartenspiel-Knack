# Knack-Spiel

Dieses Repository enthält zwei eigenständige Webseiten zum Knack-Spiel. Sie werden getrennt entwickelt und dokumentiert:

| Version | Webseite | Dokumentation |
| --- | --- | --- |
| Mirko | [`Knack.html`](./Knack.html) | [Technische Dokumentation](./docs/versionen/mirko.md) |
| Google AI Studio | [`ai-studio/index.html`](./ai-studio/index.html) | [Versionseinstieg](./ai-studio/README.md) und [technische Dokumentation](./docs/versionen/ai-studio.md) |

## Weitere Spiele

- [Zauberwürfel 3D](./Zauberwuerfel-3D/index.html) ist eine eigenständige Webseite zum interaktiven Drehen und Lösen eines 3×3-Zauberwürfels. Hinweise zur Bedienung stehen in der [Projektanleitung](./Zauberwuerfel-3D/README.md).
- [König und Bettler](./koenig-und-bettler/index.html) ist ein eigenständiges Kartenspiel für 3 bis 8 Personen und Bots, mit pausierbarem Demo-Modus, dezenten Klängen und PeerJS-Multiplayer. Beim Beitreten genügt die vierstellige Raumnummer; die Spielanleitung ist über „📖 Regeln“ erreichbar.

## Dokumentation

- [Gemeinsame Spielregeln](./docs/spielregeln.md) beschreiben den dokumentierten fachlichen Kern und kennzeichnen versionsspezifische Abweichungen.
- [Entwicklungs- und Dokumentationsprozess](./docs/entwicklung.md) beschreibt, wann die Dokumentation mit dem Code zu aktualisieren ist.
- [Architekturentscheidung ADR-0001](./docs/entscheidungen/ADR-0001-zwei-implementierungen.md) hält fest, warum beide Webseiten vorerst getrennt bleiben.

Die Originaldateien außerhalb dieses Repositorys werden durch die aufgenommenen Kopien nicht verändert.
