# Zauberwürfel-Notation (Übersicht aller Buchstaben)

| Buchstabe | Bedeutung (Englisch) | Bewegung / Ebene |
| :--- | :--- | :--- |
| **F** | **F**ront | Dreht die vordere Seite im Uhrzeigersinn. |
| **B** | **B**ack | Dreht die hintere Seite im Uhrzeigersinn. |
| **U** | **U**p | Dreht die obere Seite im Uhrzeigersinn. |
| **D** | **D**own | Dreht die untere Seite im Uhrzeigersinn. |
| **L** | **L**eft | Dreht die linke Seite im Uhrzeigersinn. |
| **R** | **R**ight | Dreht die rechte Seite im Uhrzeigersinn. |
| **M** | **M**iddle | Dreht die mittlere Ebene zwischen L und R (wie L). |
| **E** | **E**quator | Dreht die mittlere Ebene zwischen U und D (wie D). |
| **S** | **S**tanding | Dreht die mittlere Ebene zwischen F und B (wie F). |
| **x** | x-Achse | Dreht den gesamten Würfel auf der x-Achse (wie R). |
| **y** | y-Achse | Dreht den gesamten Würfel auf der y-Achse (wie U). |
| **z** | z-Achse | Dreht den gesamten Würfel auf der z-Achse (wie F). |

Alle Züge können mit einem Apostroph (`'`) gegenläufig oder mit `2` um 180° ausgeführt werden, z. B. `M'`, `x2` oder `S2`. Züge werden in der Zugfolge durch Leerzeichen oder Kommas getrennt.
